# Anti-Patterns

This folder collects theory notes about recurring design and implementation mistakes.

The documentation is split into three focused pages:

- `object_oriented_programming.md` for object-oriented design anti-patterns
- `cpp.md` for C++-specific anti-patterns
- `python.md` for Python-specific anti-patterns

These pages were written from a combination of repository style conventions and external reference material.
Each page contains its own web references.

# Generated Version.hpp

## Overview

`Version.hpp` is generated by CMake configuration in the watchlist repo. Do not make manual source changes to it as part of normal coding work.

## Workflow

1. Avoid editing `Version.hpp` directly, including for version strings, generated constants, comments, or formatting.
2. If a requested change appears to require editing `Version.hpp`, look for the generator, template, CMake configuration, or source metadata that produces it instead.
3. If a CMake configure or build step changes `Version.hpp` incidentally, treat that as generated output, not as the primary authored change.
4. Do not revert incidental `Version.hpp` changes unless the user explicitly asks and doing so will not discard user work.
5. Mention any incidental generated-file change in the final response when it is visible in the working tree.

## Allowed Actions

- Read `Version.hpp` to understand compile errors, generated symbols, or diffs.
- Leave CMake-generated updates in place after a user-requested configure or build.
- Explain that the file is generated when a user asks why it changed.

## Disallowed Actions

- Do not hand-edit `Version.hpp`.
- Do not present `Version.hpp` edits as intentional implementation work unless the user specifically requested generated-version-file work.
- Do not run CMake configure, builds, or tests solely for this skill unless the user asks.
